# Consultora · demo sintética

Catálogo de ejemplos precalculados con empresas ficticias. No recibe archivos
ni datos de clientes; no ofrece servicios financieros ni transacciones.

Demo: https://afritocreator.github.io/Consultora-demo/

Los HTML se generan desde el proyecto privado Consultora. Este repositorio
contiene únicamente sus resultados sintéticos y la configuración de publicación.
Las cifras requieren revisión de supuestos antes de cualquier uso profesional.

Cada página permite volver al catálogo y descargar una copia HTML.
GitHub Actions publica automáticamente los cambios de `main` en Pages.
